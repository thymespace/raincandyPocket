# raincandyPocket
tamagochi-lite website featuring Ame from Needy Girl Overdose. designed primarily for use with [iiSU](https://github.com/iisu-network/iiSU)'s web widgets, but can function in other contexts.
<br>
『Needy Girl Overdose』のあめちゃんをフィーチャーしたたまごっちぽいのウェブサイト。[iiSU](https://github.com/iisu-network/iiSU)のウェブウィジェットでの使用を主に想定して設計されていますが、他の環境でも動作します。
